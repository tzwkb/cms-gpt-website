## 概览

带 GPT 类 AI 集成能力的 CMS 网站项目，包含 PHP 与 Python 相关组件。

## 主要能力

- 提供 CMS 网站基础结构。
- 集成 GPT-like AI 功能。
- 适合作为早期 Web/AI 集成项目参考。
